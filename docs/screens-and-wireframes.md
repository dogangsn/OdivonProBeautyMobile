# Screens and wireframes

```text
+------------------------------+
| branch / role          alerts|
|                              |
| contextual hero / KPI        |
|                              |
| appointment or task cards    |
| appointment or task cards    |
|                              |
| [Today] [Customers] [KPI]    |
+------------------------------+
```

Customer navigation: phone OTP, live appointments, booking, package balance, favorite specialist, notification preferences and KVKK. Staff/manager navigation: daily plan, check-in, clinical session parameters, photo flow, authorized customer history, finance, stock, campaign, commission, KPI and notifications.

Material 3 uses indigo seed colors, system light/dark mode, semantic labels, 44px targets and bottom navigation suitable for one-hand use. Loading, empty, offline, denied and `not-configured` states are explicit. Sensitive content is hidden from notification previews and recent-app snapshots in the production hardening phase.
